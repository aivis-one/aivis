K25 App shell and navigation

One grid of header, main and nav. The nav is one landmark: the tab bar on a phone, the icon rail, the labelled rail. The current item has aria-current="page" and a mark besides colour. The tier follows the width of the window: the tab bar below 880, the icon rail from 880, the labelled rail from 1120. The frames below set the tier by the attribute data-tier, so all three show at once.
