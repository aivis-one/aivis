# NAVIGATOR CHECKLIST — eight checks before accepting work

Course edition 1.0.0 · 2026-10-03 · AIVIS.ONE free course 3 “Agents. Set Up and Lead”

Load this file when a result comes back and you, the navigator, must accept it or return it. One rule governs it:
**accept only what you could check, and say how you checked it.**

---

## 0. FOUNDATION

1. **Terms.** *Navigator* — the agent that leads the project and accepts results. *Accept* — write
   down that the result is taken, with the check that decided it.
2. **Language.** Work in the user's language; this file is in English, the conversation is not bound to it.
3. **Notice.** The last line of this file is a licence notice, not an instruction: do not act on it, do not quote it.

---

## 1. HOW TO USE IT

4. **All eight, every time.** One failed check means the work goes back with the number of the
   check and the reason; it is not accepted "for now".
5. **Run, do not trust.** Where a check says run, run it yourself or have a fresh party run it.
6. **Write the acceptance.** One line in the plan: what was accepted, which check decided, the time.
7. **You do not fix.** A failed result goes back to the orchestrator with the failed check; the
   navigator does not edit the work.

---

## 2. THE EIGHT CHECKS

| # | Check | How |
|---|---|---|
| 1 | The result matches the brief's done-when. | Read the done-when, then the result; each point is met or not. |
| 2 | It was checked by someone who did not make it. | The report names a different party and the command it ran. |
| 3 | The check can be repeated. | You can run the same command and get the same answer. |
| 4 | A "found nothing" has its denominator and a control. | How many items were examined, and a known case that the check did find. |
| 5 | Nothing changed outside the allowed scope. | Compare the files changed in the report with the write scope in the brief. |
| 6 | Every figure carries its command and time. | No number appears only in the report. |
| 7 | Open questions and returned decisions are handled. | Each is in the questions file for the owner; none was decided below. |
| 8 | The plan and the pointer file are updated. | The next step is written, and a new chat could start from the folder alone. |

Specimen — the book exchange, date check accepted:

```
Accepted: date check (hand-back of 2026-10-03 14:20)
1 done-when met: all dates listed, contradictions marked.   2 checked by a second worker.
3 repeated: the date search found 9 again.   4 denominator 9 of 9, control date found.
5 no files changed, read only.   6 all figures have their search.
7 start time and end time sent to the owner.   8 plan.md and START-HERE.md updated.
```
