WCAG CONTRAST RULES
Accent #E8651A on white
Ratio ≈ 3.5:1 — FAIL AA small text
✓ Pass AA large text (≥18px bold / ≥24px)
→ Use for headings, stat numbers, buttons. Never for body copy <18px.
Primary #cc3203 on white
Ratio ≈ 4.8:1 — PASS AA all sizes
→ Safe for any text on white.
Light #EFB44C on white
Ratio ≈ 1.9:1 — FAIL all text
→ Decorative only: progress bars, borders, icon bg tints. Never for text.
Accent #E8651A on teal-800
Ratio ≈ 2.8:1 — FAIL AA small text
✓ Pass AA large text (≥18px bold / ≥24px)
→ Hero labels must be ≥14px bold (font-section-label).
